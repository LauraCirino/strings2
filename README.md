# strings2

programas que demonstram a manipulação de strings em python

---
## 📚 Aprendizados
- fatiamento de strings
- strings de multiplas linhas

## ⚙️ Funcionalidades
- atividae1: exibe recortes de uam string de acorodo com os criterios determinados atraves do fatiamento
- atividade2: exibe emnsagens de multiplas linhas
- atividade3:mansagem secreta exibida atravez de fatiamneto de strings


## 🛠️ Stack
- python

```bash
